# Lab 02 — AI in Everyday Challenges (Group Activity)

## 1. Laboratory Session
- **Lab number:** 02
- **Title:** AI in Everyday Challenges
- **Group Scenario:** Group 5 — The Busy Student
- **My Role:** Product Ideation, Prompt Engineering, and Mock-up Generation

## 2. Objective
To use a Large Language Model as a product-development partner to ideate, structure, and design an innovative AI application that solves a real-world student problem (time management and academic stress).

## 3. Tasks and Implementation
1. **Problem Definition:** University students struggle to manage multiple deadlines across different modules, leading to procrastination, missed tasks, and stress.
2. **LLM-Assisted Ideation:** I prompted an LLM (ChatGPT) to act as a product manager. I instructed it to generate an innovative concept, name, features, and a visual mock-up.
3. **Product Concept:** 
   - **Name:** StudySync AI
   - **Tagline:** Your personal AI study planner – Study smarter, stress less.
   - **Target User:** 2nd-year university students balancing heavy academic loads and extracurriculars.
   - **Key Features:** 
     1. *Dashboard & Study Tips:* Shows total study time, tasks completed, and AI suggestions.
     2. *Smart Planner:* A calendar view showing pending tasks and estimated time required.
     3. *AI Assistant:* A built-in chatbot that helps students with homework and study plans.
4. **Mock-up Design:** Generated using ChatGPT's image generation feature. The resulting mock-up provides a high-fidelity visual representation of the app interface.

## 4. Results and Evidence
*The LLM successfully generated a complete product concept, including a high-fidelity UI mock-up. The resulting app, "StudySync AI", directly addresses the "Busy Student" problem by providing a centralized, AI-driven hub for scheduling and academic support.*

*(See `/screenshots` folder for the full ChatGPT conversation and the generated UI mock-up).*

## 5. Observations
- **LLM as a partner:** Using the LLM was incredibly efficient. It generated a complete concept, marketing tagline, and visual design in a single prompt. 
- **AI Capability:** I was surprised that the AI didn't just write text, but actually generated a coherent, visually appealing UI mock-up showing how the features would look on a phone screen. 
- **Limitations:** While the UI looks great, the AI doesn't actually build the working app. As the human developer, I had to critically evaluate if the features (like the AI Assistant) are realistic and feasible to build in a real-world scenario.

## 6. Learning Outcomes
- Can use structured prompting to use an LLM as an effective brainstorming and product design tool.
- Learned how to leverage multimodal AI (text + image generation) to rapidly prototype an idea.
- Can translate AI-generated text concepts into a visual prototype for presentation.
